MIDI Companion: build log

A browser MIDI player and Synthesia-style visualizer, built in a week with Claude Code. Notes fall onto an 88-key piano, and Learn mode waits at each chord until I play it on my own MIDI keyboard. These are the 34 entries of my log, with one sentence on each.

  • 12 to 16 October 2026
  • Vite + TypeScript + Canvas 2D
  • Claude Code
  • No UI framework

Open the app Read the full log Source on GitHub

Monday 12 October

  1. 1

    Picking the idea and the stack

    I picked the MIDI visualizer idea, studied midee for ideas only because it has no license, and chose Vite, TypeScript and Canvas 2D with no framework.

  2. 2

    Repo setup

    I set up the repo with a CLAUDE.md, this log and a .gitignore, and made lowercase file names a rule for all my artifacts.

  3. 3

    Scaffolding the Vite project

    I scaffolded the project after checking Node's version and every package's license, and got a blank page building with strict TypeScript.

  4. 4

    First deploy to Vercel

    I deployed the blank page to Vercel from GitHub for the first time, so every push to main now redeploys the site.

  5. 5

    Parsing a MIDI file

    I added a MIDI parser and a generated test file, and confirmed the notes it read matched what we wrote and what midee showed.

  6. 6

    Falling notes and the keyboard, v1

    I built the one clock, the 88-key layout and the canvas drawing, so notes fall onto the keyboard exactly on time.

  7. 7

    Seek slider, frame rate, and darker black-key notes

    I added a seek slider and a frame counter and measured a steady 165 fps with a real song, which is why I never needed PixiJS.

  8. 8

    Piano sound and sync

    I added a real piano sound from the Salamander recordings through Tone.js, and tested that the sound stays in sync with the falling notes.

  9. 9

    Edge cases and a pause bug

    I handled bad files, drum tracks and background tabs, and Claude found a bug where pausing didn't actually stop the sound, which we fixed.

  10. 10

    Keys light up while their note plays

    I made keys light while their note plays and colored the notes by track so the two hands can be told apart.

  11. 11

    Playing the keys with the mouse

    I made the on-screen keys playable with a mouse or a finger, including gliding across them.

Tuesday 13 October

  1. 12

    Web MIDI input, step 1: listen only

    I made the page read my DONNER N25 and print its notes, after Claude showed me the docs and what they didn't confirm.

  2. 13

    Web MIDI input, step 2: my keyboard plays the piano

    I made my keyboard play the piano and light the keys, and learned that pressing harder changes only the volume.

  3. 14

    Tabs and Learn mode

    I built the Autoplay, Free play and Learn tabs, where Learn waits at each chord until I play it, and found while testing that holding a key early let me cheat.

  4. 15

    Hosting the piano samples myself

    I copied the piano recordings into the repo with a one-year cache time, so the site no longer depends on Tone.js's server and a visitor's browser keeps the recordings after the first visit.

  5. 16

    Settings button with the credits

    I added a Settings button with the credits inside, so the piano credit the license asks for is always one click away.

  6. 17

    Silent keys before the first click, and a loud blast after

    I found that keys pressed before the first click all sounded at once, loudly, after the click, and we fixed the code that queued them.

  7. 18

    The hand picker, and not cutting off the other hand

    I added a hand picker, worked out which track is which hand from real song data, and stopped the other hand from being cut off whenever Learn waits.

  8. 19

    Test songs for the edge cases

    I had six edge-case test songs made whose correct results are known, so I don't have to check every case by hand.

  9. 20

    A welcome screen and a song popup

    I built a welcome screen and a drag-and-drop song popup, after telling Claude its first version had far too much text.

  10. 21

    The welcome card grows up, and the computer keyboard plays

    I gave the welcome card a title and a MIDI status pill, made the computer keyboard play the piano, and made dropping a file anywhere work.

  11. 22

    Volume, playback speed, and a sustain pedal

    I added volume, a speed button from 0.25x to 2x, and a sustain pedal on the space bar or a MIDI pedal, and confirmed it works with my keyboard's sustain button.

  12. 23

    The floating control bar

    I built a control bar I can drag that snaps to edges and corners and remembers where I leave it.

  13. 24

    NOW PLAYING and a Tracks popup

    I added a NOW PLAYING pill and a Tracks popup that lists each track and lets me switch tracks off, checked against the real track data.

  14. 25

    The look, the Settings panel, and separate songs

    I gave the whole app a modern look with a self-hosted font, glass panels, glows and animation, and built the Settings panel and separate songs for Autoplay and Learn.

Wednesday 14 October

  1. 26

    Tempo, a metronome, and the welcome song list

    I added the song's tempo and a metronome (Tone.js has none, so we built one), and a test caught a real bug in Claude's tempo code.

  2. 27

    Settings, tooltips, backgrounds, and small fixes

    I added a hold-to-reset button, my own tooltips, switches to hide header chips, and background colors including a light White.

  3. 28

    Smooth scrolling, a tab-switch bug, and a crash from the inspector

    I found three bugs by testing (a silent piano after switching tabs, choppy sound on a quick switch, and a crash when opening the inspector), and we fixed them.

  4. 29

    A folder of my own songs

    I added a "Your folder" picker for Chrome and Edge so I can play songs straight from a folder on my computer.

  5. 30

    Fit the piano to the song, and only labelling the C keys

    I added a setting that shows only the octaves a song uses, and another that labels only the C keys.

  6. 31

    Chips, key names, a set octave range, a glow that follows the music, and phones

    I added computer-key names, an octave range I can pick, a background glow that follows the music, and the first phone layout.

Thursday 15 October

  1. 32

    The "!" button for MIDI, a two-row dock, a short welcome card, and trying it on my phone

    I added a "!" button that explains MIDI problems on phones, shrank the dock and welcome card, and checked it on my real phone for the first time.

Friday 16 October

  1. 33

    Menus for short windows, a touch-friendly octave window, and particles

    I made the menus fit short windows, made the octave window work with touch, and added particles that fly from the keys.

  2. 34

    A Learn score, a limited octave range, grouped Settings, new colors and a softer key glow

    I added a Learn score, a limited octave range for smaller keyboards, regrouped Settings, added colors, and softened the key glow.

The full log also has a list of where Claude misread me or I had to correct course, and a list of decisions and abandoned ideas.
